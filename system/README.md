# system/

Core engine architecture and system definitions for HYDRA.

## Purpose

This folder defines the structural heart of HYDRA — the engines and interfaces
that make up the operating system. It is the home for:

- The Decision, Knowledge, and Prompt engine definitions.
- Interfaces and contracts between engines.
- Shared system-level configuration and orchestration structure.

Everything here describes *how HYDRA is built*. Business logic is introduced
only when its milestone in the roadmap is reached.
