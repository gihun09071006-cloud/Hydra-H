# prompts/

Prompt templates and prompt-engineering assets for HYDRA.

## Purpose

This folder holds the reproducible prompt structures that HYDRA uses to drive
creative and language models. It is the home for:

- Structured prompt templates and their schemas.
- Reusable prompt fragments and building blocks.
- Prompt-engineering references and versioned variants.

The Prompt Engine composes these assets into deterministic, schema-conformant
prompts so that identical inputs produce identical output.
