# docs/

Documentation and design notes for HYDRA.

## Purpose

This folder holds long-form documentation that supports the system beyond the
top-level specification and roadmap. It is the home for:

- Architecture deep-dives and design decisions.
- Engine-level documentation as each engine is built.
- Diagrams, reference guides, and conceptual explainers.
- Contribution and process notes.

Documentation here expands on `HYDRA_SPEC.md` and keeps the reasoning behind
the system's design discoverable and current.
