# data/

Datasets, schemas, and structured records for HYDRA.

## Purpose

This folder holds the structured data that flows through HYDRA. It is the home
for:

- Output and input schemas that define HYDRA's data contracts.
- Reference datasets and structured records.
- Fixtures used by tests and examples.

Schemas defined here keep every engine's input and output predictable and
validatable. Generated data artifacts are excluded from version control.
