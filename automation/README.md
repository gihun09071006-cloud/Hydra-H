# automation/

Workflow orchestration and channel delivery for HYDRA.

## Purpose

This folder is the automation layer that connects HYDRA to the outside world.
It is the home for:

- Workflow orchestration between engines and stages.
- Channel integrations that deliver output (e.g. Telegram).
- Scheduling, triggers, and pipeline definitions.

Automation logic is added in its designated roadmap milestone. Until then, this
folder defines where orchestration and delivery will live.
